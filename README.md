# Wreso — онлайн-видеоредактор (SaaS)

Веб-приложение на **Node.js + MySQL + FFmpeg**: регистрация и вход, проекты, композиции со своим холстом,
загрузка медиа и базовый монтаж прямо в браузере с экспортом в MP4.

## Возможности

- **Аккаунты** — регистрация, вход, выход (JWT в httpOnly-cookie, пароли в bcrypt, лимит попыток входа).
  Каждый пользователь видит только свои проекты и файлы.
- **Проекты** — создание, переименование, удаление; в каждом проекте медиатека и набор композиций.
- **Композиции и холст** — размер кадра (пресеты 16:9, 9:16, 1:1, 4K или свой), FPS, цвет фона,
  фиксированная или автоматическая длительность. Композиции можно дублировать.
- **Медиа** — загрузка видео (MP4, MOV, WebM, MKV, AVI…), аудио (MP3, WAV, AAC, FLAC, OGG…) и изображений
  (JPG, PNG, WebP…) с drag & drop и прогрессом. Сервер определяет длительность и размеры (ffprobe),
  делает превью-кадр, волновую форму звука и, при необходимости, прокси-копию для браузера.
- **Монтаж** (таймлайн с несколькими видео- и аудиодорожками):
  - **нарезка** — разрез по курсору (`S`), удаление, удаление со сдвигом, дублирование;
  - **обрезка** — перетаскивание краёв клипа или точные значения входа/выхода, кадрирование краёв кадра;
  - **скорость** — от 0.1× до 10× (видео и звук, высота тона сохраняется);
  - **аудио** — громкость до 400 %, отключение звука клипа/дорожки, плавное появление/затухание,
    «отделить звук» от видео на отдельную аудиодорожку, фоновая музыка на аудиодорожках;
  - **кадр** — масштаб, позиция (можно тащить клип прямо на холсте), непрозрачность, «заполнить холст»;
  - **соединение** — кнопка «⇤ Соединить» склеивает клипы дорожки без промежутков; композицию можно вложить
    в другую композицию или присоединить в конец (`⇥`) — так собирается ролик из нескольких сцен
    (циклические вложения запрещены);
  - перемещение клипов между дорожками, прилипание к краям, масштаб таймлайна, отмена/повтор, автосохранение.
- **Превью** в реальном времени на `<canvas>` и **экспорт** в MP4 (H.264 + AAC) через FFmpeg с очередью
  рендеров, прогрессом, просмотром и скачиванием результата.

## Быстрый старт через Docker

```bash
JWT_SECRET=$(openssl rand -hex 32) docker compose up --build
```

Откройте http://localhost:3000 и зарегистрируйтесь. Данные MySQL и медиафайлы хранятся в volume-ах.

## Запуск без Docker

Требуется Node.js 18+, MySQL 8 (или MariaDB 10.6+) и FFmpeg (`ffmpeg` и `ffprobe` в `PATH`).

```bash
# 1. База данных и пользователь
mysql -uroot -p -e "CREATE DATABASE wreso CHARACTER SET utf8mb4;
  CREATE USER 'wreso'@'localhost' IDENTIFIED BY 'wreso';
  GRANT ALL ON wreso.* TO 'wreso'@'localhost';"

# 2. Настройки
cp .env.example .env        # укажите доступ к БД и JWT_SECRET

# 3. Установка и запуск (схема sql/schema.sql применяется автоматически)
npm install
npm start                   # или npm run dev — с перезапуском при изменениях
```

Схему можно применить отдельно: `npm run migrate`. Тесты: `npm test`.

## Переменные окружения

| Переменная | По умолчанию | Описание |
|---|---|---|
| `PORT` | `3000` | порт HTTP-сервера |
| `JWT_SECRET` | — | секрет подписи сессий (обязателен при `NODE_ENV=production`) |
| `COOKIE_SECURE` | `false` | `true`, если приложение работает по HTTPS |
| `DB_HOST` / `DB_PORT` / `DB_USER` / `DB_PASSWORD` / `DB_NAME` | `127.0.0.1` / `3306` / `wreso` / `wreso` / `wreso` | подключение к MySQL |
| `DB_AUTO_MIGRATE` | `true` | применять `sql/schema.sql` при старте |
| `STORAGE_DIR` | `./storage` | где хранить медиа, превью и рендеры |
| `MAX_UPLOAD_MB` | `2048` | максимальный размер одного файла |
| `FFMPEG_PATH` / `FFPROBE_PATH` | `ffmpeg` / `ffprobe` | пути к бинарникам FFmpeg |
| `RENDER_CONCURRENCY` | `1` | сколько рендеров выполнять одновременно |

## Архитектура

```
public/                  SPA без сборки (ES-модули)
  js/pages/              вход/регистрация, проекты, проект, редактор
  js/editor/             модель таймлайна, превью на canvas, таймлайн, инспектор
src/
  server.js              Express: API + статика
  routes/                auth, projects, media (загрузка), compositions (таймлайн, рендеры)
  services/ffmpeg.js     ffprobe, превью, waveform, прокси
  services/renderer.js   сборка filter_complex FFmpeg из дорожек и клипов
  services/renderQueue.js очередь рендеров (статусы в таблице renders)
sql/schema.sql           схема MySQL
```

**Модель данных**: `users` → `projects` → (`media`, `compositions`) → `tracks` → `clips`; `renders` — экспорт.
Клип ссылается на медиафайл или на другую композицию (вложение) и хранит: позицию на таймлайне
(`timeline_start`), отрезок источника (`source_in`/`source_out`), скорость, громкость, затухания,
кадрирование, позицию/масштаб/прозрачность на холсте. Длительность клипа = `(source_out − source_in) / speed`.

Редактор сохраняет весь таймлайн композиции одним запросом `PUT /api/compositions/:id/timeline`
(в транзакции, с проверкой принадлежности медиа проекту, границ источника и отсутствия циклов вложения).
Экспорт строит один граф FFmpeg: цветной фон размера холста → наложение клипов снизу вверх (`overlay`)
с `setpts`/`crop`/`scale`/`fade`, звук — `atrim`/`atempo`/`volume`/`afade`/`adelay` → `amix`.
Вложенные композиции сначала рендерятся во временные файлы.

## REST API (кратко)

| Метод | Путь | Назначение |
|---|---|---|
| POST | `/api/auth/register`, `/api/auth/login`, `/api/auth/logout` | аккаунт |
| GET | `/api/auth/me` | текущий пользователь |
| GET/POST | `/api/projects` | список / создание проекта |
| GET/PATCH/DELETE | `/api/projects/:id` | проект с медиа и композициями |
| POST | `/api/projects/:id/media` | загрузка файлов (`multipart/form-data`, поле `files`) |
| GET/PATCH/DELETE | `/api/media/:id` | медиафайл; `/file`, `/thumbnail`, `/waveform` — содержимое |
| POST | `/api/projects/:id/compositions` | новая композиция |
| GET/PATCH/DELETE | `/api/compositions/:id` | композиция (GET — вместе с дорожками и клипами) |
| POST | `/api/compositions/:id/duplicate` | копия композиции |
| PUT | `/api/compositions/:id/timeline` | сохранить дорожки и клипы |
| GET/POST | `/api/compositions/:id/renders` | список / запуск экспорта |
| GET/DELETE | `/api/renders/:id` | статус рендера; `/file?download=1` — скачать MP4 |

## Ограничения

- Превью в браузере — приблизительное (синхронизация HTML5-видео); точный результат даёт экспорт.
  Громкость выше 100 % слышна только в экспорте.
- Вложенная композиция в превью показывается по её последнему рендеру (или заглушкой, если рендера нет).
- Очередь рендеров работает внутри процесса; для нескольких серверов её стоит вынести в отдельный воркер.
